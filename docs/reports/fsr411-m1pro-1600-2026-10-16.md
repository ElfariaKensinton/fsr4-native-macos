# FSR 4.1.1 profile check on M1 Pro at 1600p

An interleaving-free CLI benchmark used the same generated 8-frame input at
1280×800 → 2560×1600, the `int8-simd` backend, quality preset, and 10 measured
sequences per run. It compared the full-network `exact-fast` profile with Lite
(`lossy`).

| Profile | Mean GPU time per upscaled frame | Neural/reused frames |
| --- | ---: | ---: |
| `exact-fast` | 43.78 ms | 80 / 0 |
| Lite (`lossy`) | 28.23 ms | 40 / 40 |

Lite reduced the upscaler command-buffer time by **35.5%** in this run (about
1.55× the upscaler throughput). This is the FSR path alone; it does not predict
game FPS because game rendering, CPU work, and synchronization are not included.

The captured CrossOver session in `hook.log` was using `exact-fast` at
2560×1600, even though Lite was the requested install profile. The installer
now writes its chosen profile into `panel.conf` so an older panel preference
cannot silently select the full network on installation. The panel remains
available for later switching.
